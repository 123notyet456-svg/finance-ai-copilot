# 外部文档与多轮会话

## 文档链路

```text
网页上传
  -> 类型/大小校验
  -> PDF / DOCX / Markdown / TXT 文本提取
  -> SHA-256 + 版本元数据
  -> 切分数量记录
  -> 发布为 ready
  -> 下次问答重建当前有效语料索引
```

- 限制：10 MB；不支持其他扩展名。
- 扫描 PDF 未接 OCR，不会伪造提取结果。
- 停用文档不参与下一次索引，旧向量在语料替换时清除。

## 会话链路

```text
原始追问 + 上一轮独立问题
  -> 确定性问题补全
  -> 重新检索制度
  -> 证据门禁
  -> 答案或 needs_review
  -> 追加会话消息和审计记录
```

示例：“上海出差住宿标准是什么？”后追问“那北京呢？”，检索问题会补全为“北京出差住宿标准是什么？”。历史仅用于问题补全，不替代本轮证据检索。
