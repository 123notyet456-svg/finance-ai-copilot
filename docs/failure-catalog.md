# 失败案例目录

## 用途

统一记录可复现失败并转化为回归测试。

候选类型：`RAG_NO_EVIDENCE`、`RAG_WRONG_RETRIEVAL`、`RAG_CITATION_MISMATCH`、`RAG_POLICY_CONFLICT`、`RAG_UNSUPPORTED_CLAIM`、`OCR_UNREADABLE`、`OCR_FIELD_MISSING`、`OCR_FIELD_INCORRECT`、`RULE_FALSE_POSITIVE`、`RULE_FALSE_NEGATIVE`、`DUPLICATE_MISSED`、`PROVIDER_TIMEOUT`、`UNSUPPORTED_FILE`、`SCHEMA_VALIDATION_ERROR`。
